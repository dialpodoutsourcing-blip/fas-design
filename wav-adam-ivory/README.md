# WAV · ADAM Member Area · Ivory Edition (v6.1, premium)

A second, fully different design of the same product, built on the
Winfuel Authority Ventures brand board. Chat ready and voice orb ready.

## How it differs from v5.1 (dark edition)
| | v5.1 Dark | v6 Ivory |
|---|---|---|
| Page | Simple Black | Crispy Ivory paper |
| Sidebar | Dark | Simple Black, gold gradient for the active page |
| Feel | Night dashboard | Editorial, like the brand's slides and landing page |
| Specialists | Card grid | Chapter index (numbered gold squares, like the brand's Table of Contents slide) |
| Next step | Single dark card | Split: black marble with ADAM's orb, ivory page with the step |
| Chat | Chat bubbles | Transcript: ADAM's question set in large Bebas, your answers in black cards |
| Voice | Panel | Black marble stage with gold veins |
| Review | Cards | A printed document on white paper with a gold page fold |

## Brand elements used
Simple Black, Crispy Ivory, Leather, White, Gold Gradient ·
Bebas Neue, Montserrat, Inter · black-gold marble veins · gold page fold ·
circular gold light (ADAM) · numbered gold squares · gold outlined icons.

## The 7 specialists keep their identity
Same shape, symbol, and jewel color as v5.1. On ivory the color is used in a darker ink
so the names stay readable: tokens `--c-anchor` to `--c-launch` in `assets/css/tokens.css`.

## Open it
1. Unzip `wav-adam-ivory.zip`.
2. Open the `wav-adam-ivory` folder.
3. Double-click `index.html`. Stay online so the brand fonts load.

## Developer hooks
Same as v5.1. Read the top of `assets/js/adam.js`:
`fas:send`, `fas:mic`, `FAS.chat.addMessage()`, `FAS.orb.setState()`, `FAS.voice.setTranscript()`.
